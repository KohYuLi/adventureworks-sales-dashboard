# \# AdventureWorks Sales Dashboard

# 

# An end-to-end Power BI project: connecting raw data, building a relational model, writing DAX, and designing an interactive dashboard.

# 

# \## Business Scenario

# As a Business Intelligence Analyst at AdventureWorks, a global cycling equipment manufacturer, I was given a folder of raw CSV files and asked to build a dashboard for the management team.

# 

# \## Objectives

# \- Track KPIs: sales, revenue, profit, and returns

# \- Compare regional performance

# \- Analyze product-level trends

# \- Identify high-value customers

# 

# \## Tools

# Power BI Desktop · Power Query · DAX · GitHub

# 

# \## Project Structure

# ```

# adventureworks-sales-dashboard/

# ├── data/          Raw CSV files

# ├── powerbi/       Power BI report (.pbix)

# ├── screenshots/   Dashboard and data model images and analysis

# └── README.md

# ```
